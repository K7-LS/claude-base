# OpenCode

- Используй нативные инструменты OpenCode только по необходимости.
- Простой разговор не запускает tools, subagents или review.
- Провайдера и модель выбирает пользователь; общая база не задаёт их и не переключает автоматически.
- Отсутствующую возможность модели показывай как ошибку совместимости без платного fallback.
- Навыки по умолчанию закрыты и открываются только явным списком в конфигурации.
- Политика, подписка и региональные ограничения выбранного провайдера сохраняются.
- Consumer-устройство только получает обновления базы; обратная отправка данных отключена.
