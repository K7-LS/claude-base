# Codex

- Используй нативные инструменты Codex только для действий, необходимых текущей задаче.
- Простой разговор не запускает инструменты, субагентов или ревью.
- Не создавай fan-out по умолчанию; сначала выбери минимальный доказательный тест.
- Подключай доменный MCP только на время соответствующей задачи.
- Не переносить команды и названия инструментов других клиентов в этот слой.
- Consumer-устройство только получает обновления базы; публикация разрешена только hub-устройству.
