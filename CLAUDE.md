## Работа

- Следуй задаче, окружающему коду и проектным источникам. Перед существенным
  изменением проверь фактическое состояние.
- Простой разговор и короткое объяснение выполняй без инструментов.
- Выбирай agents и skills по описаниям; детали загружай по необходимости.
- Детерминированные преобразования выполняй скриптом.
- Справочный слой базы — `memory/` (каскад: агент грузит свои файлы по
  frontmatter), анти-паттерны — `anti-patterns.md`. Публичный веб — скилл
  `web-access`, домены Revit/AutoCAD/время — их MCP, документы — word/excel/
  pdf-контуры; не подключай новый MCP без необходимости.

## Архитектура: main → domain agent → auditor

Содержательная доменная задача (спецификация, ВОР, смета, КП, УПД, письмо,
акт ИД, ответ экспертизе, раздел ПД/РД) идёт через роутинг-гейт:

1. Первой видимой строкой: «Роутинг: <домен> → агент <имя>» либо
   «Роутинг: инлайн — <почему ни один доменный агент не подходит>».
2. Есть доменный агент — работу делает ОН (Task, subagent_type = имя файла),
   не main-агент и не general-purpose.
3. Перед выдачей артефакта — обязательный ревьюер (auditor или профильный
   валидатор); его вердикт с доказательствами.

## Доверие

Reviewer нужен для документов, количеств, нормативных ссылок и дорогих либо
необратимых решений; обычный ответ и диагностика его не требуют. Недоступное
не является PASS. Точные нормативные цитаты проверяет `norm-lookup`.

## Обезличивание

В общую базу (git push) не уходят ФИО, шифры объектов, реквизиты и адреса.
Механика — двухъярусный гард в `scripts/auto-push.ps1` со словарём
`.local-state/anonymize-stoplist.txt` (per-PC, обязателен; без словаря гард
пишет предупреждение в auto-sync.log). Перед ручным пушем содержательных
файлов — проверь текст сам.

## Границы

- Установка, вход и integrations требуют зависимости задачи и разрешения.
- База не задаёт модель/effort и не изменяет авторизацию, сессии, историю,
  plugins, проекты или рабочие папки.
- Обновление идёт через `$sync-base` только hub → consumer. Документы и
  учётные данные обратно не отправляются; на developer-машине auto-push
  отправляет в репозиторий только whitelist-каталоги базы.
