## Что нового в 0.4.3

- Центр запуска теперь ставится в профиль: после установки копия комплекта
  лежит в `%USERPROFILE%\.llm-foundation\launcher`, а на рабочем столе и в
  «Пуск → LLM Foundation» появляется ярлык «K7 Launch Center». Папка синка
  для ежедневной работы больше не нужна; при каждой новой установке копия и
  ярлыки обновляются. Окно «Готово» говорит, где ярлык. Если скопировать не
  удалось, установка не прерывается: в статусе будет предупреждение с
  причиной, запуск по-прежнему через `.cmd` из папки комплекта.
- Комплектный Codex CLI обновлён с 0.146.0-alpha.3.1 до стабильного
  0.153.0 (релиз 2026-09-03).

Что проверить на станции: после установки — ярлык «K7 Launch Center» на
рабочем столе открывает центр запуска; в отчёте диагностики версия Codex —
0.153.0; `bundle.manifest_version` — 0.4.3.
