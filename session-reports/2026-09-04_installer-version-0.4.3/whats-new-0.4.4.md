## Что нового в 0.4.4

- Исправлена установка Codex поверх уже установленного: раньше окно
  показывало «Codex: клиент не установлен — Client staging path contains a
  reparse point» (canary 0.4.3 на станции и ноутбуке). Причина — проверка
  продукта отвергала папку `bin` Codex, которую сам официальный установщик
  делает ссылкой (junction). Теперь такая ссылка принимается, если ведёт
  внутрь папки Codex; любая другая по-прежнему отвергается.
- Файлы установщика Codex 0.153.0 лежат в комплекте
  (`codex-package-x86_64-pc-windows-msvc.tar.gz`, `codex-package_SHA256SUMS`,
  `codex-release-0.153.0.json`): установка Codex идёт из комплекта, без
  скачивания 130 МБ на рабочем месте. Файлы сверяются по SHA-256; подменённый
  файл блокирует установку, отсутствующий — установка идёт через сеть.
- Скачивания (Claude, OpenCode, а также Codex, если файлов нет) больше не
  обрываются через 5 минут: действует контроль зависания и потолок 30 минут.

Что проверить на станции: после «Проверить план и установить» Codex
обновляется до 0.153.0 без ошибок; в отчёте диагностики `install_plans`
для codex — 0.153.0, `launch_targets` `codex-cli` RESOLVED; ярлык
«K7 Launch Center» на рабочем столе открывает центр запуска.
