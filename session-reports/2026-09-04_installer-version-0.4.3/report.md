## Грабли этой сессии
- PowerShell: имена переменных регистронезависимы — `$release = …` затирает параметр `$Release` (час на ложный след «метаданные не совпали»).
- Патчи Python в CRLF-файлах репо (`.cs`, `.py`, `.md` — w/crlf): читать/писать в текстовом режиме или нормализовать `

`; `.ps1` — LF с BOM.
- В PowerShell-вставку обёртки (`-Command` через `QuoteArgument`) не класть двойные кавычки — разделители через `[char]10`/`[char]9`.
- `sed -i` в Git Bash съедает `\` в замене (`LLM\Реворк` → `LLMРеворк`) — текст с обратными слэшами править через Python.
- Python-вывод кириллицы в Bash-инструменте падает на cp1251 — `sys.stdout.reconfigure(encoding='utf-8')` или `PYTHONIOENCODING=utf-8`.
- Транскрипт прошлой сессии: `AskUserQuestion` не использовался — вопросы владельцу были в тексте последнего сообщения (`type == assistant`, блоки `text`).
- В Git Bash нет `jq` — мониторы CI писать только через `gh … --jq`, иначе цикл молча сыпет `jq: command not found` в stderr и никогда не срабатывает.
