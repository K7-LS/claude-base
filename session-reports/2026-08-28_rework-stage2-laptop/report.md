## Правила, добытые кровью (новые)

- Движок Foundation отдаёт BLOCKED_USER_DECISION в ДВУХ формах: plan — объект
  с unknown_entries, install — ошибка без списка. Контракт-тесты должны крыть
  обе; «проверено на plan» ≠ «работает на install».
- `mcp__codex__codex-reply` теряет тред после рестарта MCP-сервера
  («Session not found» при целом rollout). Фолбэк — CLI
  `codex exec resume <threadId> -c mcp_servers.claude.enabled=false`;
  вписан в скилл codex-bridge. Финал дальше ловится монитором rollout.
- Канон hooks, совпадающий с диском байт-в-байт, — способ закрыть drift БЕЗ
  перезаписи hooks.json (перезапись сбивает доверие хукам Codex).
- PS-переносы: продолжение выражения допустимо после оператора, не перед ним
  (`('a' + \n 'b')`, не `('a' \n + 'b')`); Add-Content в WinPS 5.1 пишет
  ANSI — для логов, читаемых Python'ом, нужен `-Encoding UTF8`.
- Приёмка «свежим взглядом» другой LLM реально ловит то, что пропустили и
  автор, и его тесты (6 из 6 расхождений — по делу; зелёный набор тестов
  дефекты не покрывал). Паттерн «пакет → FAIL со списком → фикс → re-PASS»
  дешевле самопроверки.

### Механика мержа (правило на будущее)

Репозиторий требует свежие проверки на каждой ветке, а auto-merge в нём
запрещён → конвейер строго последовательный: обновить ветку → дождаться CI →
смержить → следующая. Автоматизировано монитором; в него добавлен
авто-rerun упавшего рана до 2 раз (сетевые флейки раннера: `Invoke-WebRequest`
за officecli рвётся с «connection forcibly closed»), при повторном падении —
стоп и разбор, чтобы флейк не маскировал настоящий дефект.

### Найдено по ходу (важнее самих правок)

1. **Слияние UI-блока (пп.1-3) блокируется рантаймом, а не тестами**:
   `ConnectionUiContract.Resolve` резолвит контролы через `view.FindName`,
   который НЕ пересекает namescope вложенного UserControl — при выносе упадут
   все поведенческие тесты и запуск GUI. Порядок работ поэтому: резолвер →
   флаг `--ui-visible-text-json` (закрывает 11 из 18 текстовых ассертов) →
   сам вынос XAML. Карта: `отчёты/2026-08-28-installer-карта-source-assert.md`.
2. **Два теста портят файлы ВНУТРИ бандла** (проверки tampered-состояния) —
   их нельзя переводить на общие фикстуры. Разведка этого не поймала: искала
   `shutil.copy2` в бандл, а там `write_bytes`. Проверять самому.
3. Скрытый ложноположительный: тест «о семи этапах мастера» на самом деле
   держится за `Text="Авторизация"` — заголовок колонки внутри прокси-формы.
4. Дефект вёрстки (не мой): в карточке Codex обрезан текст «Интеграция
   использует установле:».
