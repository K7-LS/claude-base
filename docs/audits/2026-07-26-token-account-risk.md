# Аудит расхода токенов и риска блокировки

Дата проверки: 2026-07-26. Отчёт не содержит prompt, raw request ID, токены
доступа и содержимое документов.

## Вердикт

1. Аномальный расход подтверждён фактическим JSONL, а не только скриншотами.
2. Причина не сводится к одному большому `AGENTS.md`: основную массу составляет
   многократное чтение уже разросшегося контекста.
3. Старая база усиливала проблему: принудительный `xhigh`, плагины, prompt/tool
   hooks, широкий автокаталог агентов и навыков.
4. Доказательств, что русский язык или русская проектная документация сами по
   себе вызывают бан, нет.
5. Геолокация — самостоятельный существенный риск: Россия отсутствует в
   актуальном списке поддерживаемых регионов Anthropic.
6. В исследованной сессии были дополнительные сигналы риска: режим
   `bypassPermissions`, shell-вызовы облачного MinerU/OpenXLab и JWT-подобное
   значение внутри команд. Это не доказывает точную причину блокировки, но
   исключает честный вывод «виновата только база или русский текст».

## Измерение токенов

Источник: локальный JSONL размером 7 399 441 байт. Анализ выполнен
`scripts/base_cli.py audit-transcript`; записи дедуплицированы по request/message
ID, наружу выведен только его SHA-256 fingerprint.

| Метрика | Значение |
|---|---:|
| Уникальные ответы модели | 168 |
| Дубли usage-записей | 380 |
| Обработанный контекст | 97 408 894 |
| Контекст + output | 97 998 788 |
| Cache-read | 95 180 814 |
| Медиана на запрос | 614 212 |
| p95 на запрос | 933 333 |
| Максимум на запрос | 979 985 |

Cache-read составляет примерно 97% всех обработанных токенов этой сессии.
Следовательно, каждый следующий model-call многократно «оплачивал» длинный
хвост истории. Даже дешёвая модель остаётся дорогой при таком контексте.

### Сравнение размера source-бандлов

Оценка vendor-neutral: `ceil(utf8_bytes/3)`. Это контроль размера пакета, а не
точный биллинг конкретного провайдера. Колонка «parent-реконструкция» получена
из предыдущего core и сопоставимого target-слоя; это не захваченный startup
prompt старого клиента и не live A/B. Колонка «новый render» — текущий
детерминированный target-бандл.

| Target | Parent-реконструкция | Новый render |
|---|---:|---:|
| Claude | 4 611 | 1 976 |
| Codex | 4 536 | 1 901 |
| OpenCode | 4 592 | 1 957 |

В рамках одного и того же оценщика source-размер ядра уменьшен с 4 184 до
1 549 токенов. Это доказывает уменьшение управляемого пакета инструкций, но не
равнозначно обещанию такой же экономии в подписочном биллинге. Одновременно:

- shared-конфиг больше не задаёт `effortLevel: xhigh`;
- плагины и marketplace не включаются общей базой;
- удалены UserPromptSubmit и PostToolUse hooks;
- простой запрос имеет бюджет `0 tools / 0 agents / 0 reviewers`;
- target-пакет активирует только компактный `auditor`, навыков по умолчанию нет;
- model/reasoning tier аудитора не фиксируется базой.

Это резко уменьшает старт, но не отменяет правило: длинную сессию нужно
заканчивать, иначе история снова станет главным расходом.

## Что найдено в риск-сессии

Структурная проверка без печати command/prompt:

- `permission_mode=bypassPermissions` встречается в 38 записях конфигурации;
- 22 shell tool-call содержат обращение к MinerU, 3 — к OpenXLab;
- в shell-командах встречаются домены `mineru.net` и
  `cdn-mineru.openxlab.org.cn`;
- 9 shell tool-call содержат JWT-подобную трёхчастную строку;
- упоминания local OSINT и remote-control есть в тексте истории, но отдельного
  tool-use с такими именами в исследованном JSONL не найдено.

Из этого следует:

- ранее использованный JWT необходимо считать раскрытым и отозвать;
- документы нельзя отправлять в облачный OCR/парсер без отдельного согласия;
- `bypassPermissions`, удалённое управление и security/OSINT automation нельзя
  держать поведением по умолчанию;
- наличие инструмента в каталоге не равно нарушению; важны фактические действия.

## Что говорят правила Anthropic

Актуальные официальные материалы:

- [Supported countries & regions](https://www.anthropic.com/supported-countries)
  не включают Россию в перечень Claude.ai/API.
- [Safeguards warnings and appeals](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals)
  перечисляет повторные нарушения Usage Policy, создание аккаунта из
  неподдерживаемого местоположения и нарушения Terms как возможные причины;
  organization может быть поставлена on hold из-за unusual activity.
- [Does Claude use my location?](https://privacy.anthropic.com/en/articles/11186740-does-claude-use-my-location)
  подтверждает обязательное использование IP и других сигналов для
  coarse-grained location и anti-abuse.
- [Usage policy update](https://www.anthropic.com/news/usage-policy-update)
  отдельно усиливает правила по malicious computer/network compromise, сохраняя
  допустимость защитной работы с согласия владельца.
- [Using dictation on Claude Mobile](https://support.claude.com/en/articles/10065434-using-dictation-on-claude-mobile)
  официально включает Russian в поддерживаемые языки диктовки.

Независимый вывод: русский язык не выглядит триггером сам по себе. Наиболее
сильные установленные риски — неподдерживаемая география, необычный объём и
agentic/security сигналы. Точную причину конкретного hold знает только
Safeguards review.

## Обязательные действия

1. Отозвать JWT/PAT/API keys, которые могли попасть в transcript или shell
   payload.
2. Подать Request a review, не заявляя неподтверждённую причину.
3. Не использовать обход геоограничений как «исправление базы».
4. Работать с Claude только в поддерживаемой юрисдикции и в соответствии с
   Terms; иначе выбирать другого провайдера через OpenCode.
5. После установки новой базы сравнить на чистом чате фактические usage первых
   3–5 простых запросов с этим baseline.

## Граница проверки

Статический budget и fake-home tests не доказывают расход подписочного клиента
в production. До живого сравнения «старый пакет / новый пакет» на одинаковых
коротких запросах результат является implementation PASS, но не full release.
